labels-niimbot import

Read the templates out of the NIIMBOT desktop app, check how they import and print one on a NIIMBOT B1 (50x30 mm labels). Use Chrome or Edge, and close the NIIMBOT phone app before printing.

This browser has no Web Bluetooth: the preview works, printing does not. Use Chrome or Edge on a computer or Android (Brave needs brave://flags/#brave-web-bluetooth-api).

1. Database file

Close the NIIMBOT app, then pick %APPDATA%\niimbot.com\NIIMBOT\Niimbot\niimbot_db.isar. The file is read in this browser only; nothing is uploaded.
