Close the NIIMBOT phone app first. Use Chrome or Edge. Every button logs what happened; use "Copy log" and paste it into the pull request.

Checking browser…

Bluetooth is switched off or there is no Bluetooth adapter. Turn it on in the system settings; this notice disappears by itself. Open the Windows Bluetooth settings
Bluetooth does not work? Browser and system setup

Chrome and Edge (Windows, macOS, Linux, Android): nothing to enable. The page must be opened from http://localhost or https://, and Bluetooth must be on in the operating system.

Brave: Web Bluetooth is off by default. Open brave://flags/#brave-web-bluetooth-api, set it to Enabled, then use Relaunch. Without it the chooser fails with "Web Bluetooth API globally disabled".

Firefox, Safari and every browser on iOS: no Web Bluetooth, use Chrome, Edge or Brave on a computer or Android.

Windows: turn Bluetooth on in Settings, Bluetooth & devices. The B1 may already show as paired; that is fine.

Printer: switched on, label roll inserted, lid closed. Close the NIIMBOT app on your phone, because a printer connected to a phone stops advertising and is not listed. The official Windows app talks to the B1 over a USB cable, so it does not block Bluetooth.

Chooser closes by itself: click Pair soon after the printer appears in the list.

Reconnect without the chooser (experimental): enable chrome://flags/#enable-web-bluetooth-new-permissions-backend (or the same address with brave:// or edge://), relaunch, connect once, then use "Reconnect". Without the flag it always answers "resolved null".

1. Connection

readRfid() asks the printer for the loaded roll's tag and logs the label counts and type; the UID, barcode and serial are masked.

Probe sends read-only queries (heartbeat, RFID, printer settings) and shows the raw replies. Tick "log raw packets" before connecting. Run it once per label roll, with the lid closed. The serial number is never written to the log.

2. Print

The preview shows exactly the black and white dots that will be sent (384 x 240 dots, 48 x 30 mm).
