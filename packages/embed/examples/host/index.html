Start Narzędzia Produkty

Start

Connect the printer once with the chip in the top bar, then move between Narzędzia and Produkty and print. The connection should stay.

  1. Close the NIIMBOT phone app and switch the B1 on with a 50 x 30 mm roll.
  2. Click "Połącz drukarkę" in the top bar, pick the printer whose name starts with B1, click Pair.
  3. Open a list, print one label, select a few rows and print them, then switch lists and print again.
